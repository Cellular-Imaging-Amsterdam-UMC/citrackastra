Automated coverage

Axis reordering, anisotropic coordinates, ordered transforms, calibration rejection, mismatched grids, HCS isolation, source preservation, overwrite refusal, memory guards, CLI types, checkpoint integrity, gaps, divisions, empty inputs and failed-run publication are tested. See GitHub Actions and the local validation record.

Practical limits

  • Sequence inference is in memory. Graph and model costs depend on object density; this is not a gigapixel streaming tracker.
  • Inference uses the original pixel grid. Physical calibration does not compensate the model input for anisotropic sampling.
  • Reference-marker tests and training overlap do not establish segmentation accuracy or independent generalization.
  • Multi-field isolation has synthetic integration coverage. The public time series are single-field test-plate wrappers, not original multiwell screens.
  • Divisions and ambiguous crossings need review. Tracklets split at divisions and gaps; inspect parent_kind and links.
  • Container validation and exact image digests are recorded in the GitHub release. Production OMERO import and Slurm roundtrip validation remain deployment checks.
